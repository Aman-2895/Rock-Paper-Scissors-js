# Rock-Paper-Scissors-js
An interactive Stone Paper Scissors web game created with HTML, CSS, and JavaScript for learning and practice.

🪨📄✂️ Stone Paper Scissors Game

A fun and interactive Stone Paper Scissors web game built using HTML, CSS, and JavaScript. This project is beginner-friendly and designed to help understand the basics of game logic, DOM manipulation, and responsive UI design.

🚀 Features

Interactive gameplay with real-time results

Clean and simple user interface

Responsive design for mobile and desktop

Random computer moves

Displays winner after each round

🛠️ Tech Stack

HTML – Structure

CSS – Styling and layout

JavaScript – Game logic

🎮 How to Play

Choose Stone, Paper, or Scissors

The computer will make a random choice

The winner is decided instantly

Play as many rounds as you want!

📂 Project Purpose

This project was created for practice and learning JavaScript basics, and it is perfect for beginners who want to understand how simple games are built using web technologies.

🌟 Preview

You can run the project by simply opening the index.html file in your browser.
